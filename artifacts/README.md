# Battery and UX display previews

These images are code-based previews using the Heltec bitmap fonts and 128×64 layout, not live simulator screenshots. Values on the home screen are illustrative.

`ui-preview.png` shows the offline home screen, menu guidance, and hold confirmation from left to right. Individual previews also include the partially filled hold indicator.

Both firmware targets compile and the host regression checks pass. Live simulator verification was blocked by an expired Wokwi license. Battery current, GPIO wake behavior, and interaction timing still need validation on physical hardware.
